A tiny Python program that writes one original line, in the cat's own voice, after sweeping a glass off the table, to /output/entry.txt for make.fun's Five Seconds to Explain the Glass bounty.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```
